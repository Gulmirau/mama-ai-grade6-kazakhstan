# Как включить рабочий кабинет iMama через Supabase

Сейчас код сайта подготовлен. Чтобы регистрация детей, родителей, учителей и ваша аналитика стали общими для всех устройств, нужно один раз подключить Supabase.

## 1. Создать проект Supabase

1. Откройте https://supabase.com
2. Зарегистрируйтесь или войдите.
3. Нажмите New project.
4. Название можно поставить `imama`.
5. Region можно выбрать ближайший доступный.
6. Дождитесь создания проекта.

## 2. Создать таблицы и защиту данных

1. В Supabase откройте SQL Editor.
2. Откройте файл `supabase/migrations/202608100001_mvp_auth_rls.sql`.
3. Скопируйте весь текст файла.
4. Вставьте в SQL Editor.
5. Нажмите Run.
6. Затем так же выполните файл `supabase/migrations/202608100002_auth_profile_trigger.sql`.
7. Затем выполните файл `supabase/migrations/202608110001_parent_child_link_rpc.sql`.

Это создаст таблицы профилей, родителей, детей, учителей, классов, учебников, тестов, прогресса, отзывов и событий. Также включаются RLS-правила: ученик видит только себя, родитель только своих детей, учитель только свой класс, админ видит всё.

Второй SQL-файл нужен, если в Supabase включено подтверждение email. Тогда запись профиля появится сразу после регистрации, даже если ребёнок ещё не подтвердил почту.

Третий SQL-файл нужен для родительского кабинета: родитель сможет привязать ребёнка по коду ребёнка, не видя чужих детей.

## 3. Взять безопасные публичные ключи

В Supabase откройте Project Settings -> API.

Скопируйте только:

- Project URL
- anon public key

Нельзя копировать в GitHub:

- service_role key
- OpenAI API key
- любые секретные ключи

## 4. Вставить ключи в сайт

Откройте файл `config.js` и заполните:

```js
window.MAMA_AI_CONFIG = {
  SUPABASE_URL: "https://ВАШ-ПРОЕКТ.supabase.co",
  SUPABASE_ANON_KEY: "ВАШ anon public key",
  ADMIN_EMAIL: "gulmirau1979@gmail.com",
  APP_MODE: "supabase"
};
```

После этого нужно заново загрузить файлы на GitHub Pages или сделать push.

## 5. Проверить регистрацию

1. Откройте публичную ссылку:
   https://gulmirau.github.io/mama-ai-grade6-kazakhstan/
2. Откройте лучше в режиме инкогнито.
3. Введите имя, город, email и пароль.
4. Выберите роль: ученик, родитель или учитель.
5. Нажмите Зарегистрироваться.
6. В Supabase откройте Table Editor -> profiles и проверьте, что появился пользователь.
7. Задайте вопрос или пройдите мини-тест.
8. Проверьте таблицы `user_events`, `test_attempts`, `progress`, `feedback`.

## Если письмо подтверждения открывает не сайт iMama

В Supabase нужно проверить адрес возврата:

1. Откройте Supabase.
2. Зайдите в Authentication -> URL Configuration.
3. В поле Site URL поставьте:
   `https://gulmirau.github.io/mama-ai-grade6-kazakhstan/`
4. В Redirect URLs добавьте:
   `https://gulmirau.github.io/mama-ai-grade6-kazakhstan/`
5. Сохраните настройки.
6. Зарегистрируйте нового тестового пользователя и нажмите ссылку в новом письме.

Если там случайно стоит другой адрес или ссылка на приложение, письмо может открываться не в iMama.

## 6. Как вы становитесь админом

В форме обычные пользователи не могут выбрать роль админа.

Админ назначается по email из `config.js`:

```js
ADMIN_EMAIL: "gulmirau1979@gmail.com"
```

Если вы войдёте именно под этим email, профиль будет создан с ролью `admin`.

## 7. Что ещё не включено автоматически

Полный AI через OpenAI и OCR фотографий учебников нельзя безопасно запускать прямо с GitHub Pages, потому что секретный OpenAI ключ нельзя вставлять в публичный сайт. Для этого следующим шагом нужна Supabase Edge Function или отдельный сервер.

Учебники сейчас подключены как каталог официальных записей и ваших загруженных материалов. Полные страницы учебников, СОР, СОЧ и ЕНТ нужно импортировать только из официальных или разрешённых источников.
