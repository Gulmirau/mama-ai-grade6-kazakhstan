# Mama AI Video Guide Script

Status: interactive guide is implemented in the app. This file is the production script for a future MP4.

## Scene Plan

1. Landing screen: child sees Mama AI and clicks "Попробовать бесплатно".
2. Grade selection: choose grade 1-11.
3. Language selection: Russian, Kazakh, or English learning language.
4. Subject selection: choose a school subject.
5. Tutor answer: Mama AI explains the task step by step.
6. Mini test: child answers and gets points.
7. Parent prompt: after the free limit, parent can create a cabinet.
8. Parent cabinet: adult creates a child profile.
9. Child link: parent copies a personal child link.
10. Child cabinet: child opens the simple cabinet without email or password.
11. Progress: parent sees points, weak topics, recommendations, and activity.

## Voiceover

Mama AI helps a child start learning without registration. The child can try a few tasks, choose a grade, language, and subject, and get a patient step-by-step explanation. When the child is ready to continue, a parent creates a cabinet, adds the child, and shares a safe personal link. The child sees only learning tools, while the parent sees progress and recommendations.
